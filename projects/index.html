NLP // Khmer LIVE

Khmer Terminology Lexicon

6,702 official Khmer–English government terms

Terms extracted with OCR from 22 scanned ministry and Royal Academy documents (7 recovered via the Wayback Machine), parsed into structured entries by an LLM. Search in Khmer or English, with a fallback to matches one syllable off. A document checker flags non-official terms in a full draft in one pass.

// Data quality: in a sample check, 20.1% of Khmer headwords were wrong (95% CI 14.7–27.3%, n=153) and 0 of 158 English glosses were (95% CI 0.0–2.4%). The check was done by an AI annotator, not yet a native speaker. Known-bad entries are listed in the README. Dataset published on Zenodo with a DOI.

Python OCR Aho-Corasick Render

NLP // Pipeline LIVE BETA

Prolong

Exam question bank for Cambodia's ministry entrance exams, built on the lexicon

Questions are drafted only from a supplied source passage, and the model must quote the sentence that answers each one; no quote, no question. A second model call, with no access to the draft step, verifies it. Source documents are OCR'd, split into passages and translated with lexicon terms forced into the output, then checked term by term. Each question stores its source excerpt, source document and who checked each control (model or human).

// Lexicon terms are linked by longest-match extraction, and a rescan re-syncs the bank when the lexicon changes. Only 5,057 of 5,889 usable entries may be forced into generated text; OCR suspects and near-duplicate spellings are excluded. A Postgres constraint blocks publishing until three human review checks pass.

NLP // RAG · Work IN USE

Khmer Document Pipeline

RAG that drafts official Khmer letters and reports for the EGD program at Techo Startup Center

Retrieves the most similar past documents from a ChromaDB index of ~1,450 Khmer and English letters, reports and lexicon entries (multilingual-e5-base or gemini-embedding-001). Gemini 2.5 Pro writes each section from those exemplars and the source notes. Rule-based guards then check every section: required names and figures kept verbatim, unknown facts left as placeholders, register, loanword rendering, and wrong-script characters (a 205-pair table from Unicode names and UTS #39 confusables, generated by the lexicon library). Failures are retried with the fault list; output is a formatted .docx.

// Register rules were mined from 273 reports (330K tokens) and 1,601 tracked-change edits by senior reviewers. At intake, 280 of 307 Khmer PDFs had broken font maps that extract as malformed Unicode; a detector for impossible sequences (dangling coeng, stacked vowel signs) sends those to OCR instead. Digits in OCR output are masked for manual checking, because Khmer OCR misreads them.

Python ChromaDB multilingual-e5 Gemini
