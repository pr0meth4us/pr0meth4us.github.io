// Khmer language & NLP

NLP // Khmer LIVE

Khmer Terminology Lexicon

5,929 official government terms, searchable

Fifteen official sources that existed only as scanned paper. Search in Khmer or English; when nothing matches exactly it looks one syllable away, because Khmer is hard to type correctly. A second mode checks a whole draft document against the set in one pass and flags unofficial wording.

// The data is OCR output parsed by an LLM. Nobody has checked it against the source PDFs, and there's no accuracy figure. Known-bad entries are listed in the README.

NLP // Pipeline IN PROGRESS

Prolong

Ministry exam prep, built out of scanned paper

OCR and an LLM turn scanned Khmer ministry exam material into a structured question bank, each question mapped to the lexicon so a dictionary fix re-syncs the whole bank. Recall is measured by hand-annotating a sample, not asserted.

CV // OCR LIVE

Cambodian Licence Plate Recognition

Reading Khmer glyphs off moving traffic

Fine-tuned YOLO segmentation locates the plate; PARSeq reads it. Trained on Cambodian plates specifically, because the off-the-shelf models are trained on Latin characters and fail on Khmer ones.
