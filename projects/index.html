NLP // Khmer LIVE

Khmer Terminology Lexicon

Technical vocabulary for a low-resource language

5,929 approved Khmer renderings of technical, legal and administrative terms, drawn from 15 official sources that existed only as scanned paper — a person could look a term up, a program could not. Search works in Khmer or English and tolerates misspelling: when nothing matches exactly it looks one syllable away. 80% of entries carry a full Khmer definition. A second mode runs a draft document against the whole set in a single Aho-Corasick pass and flags unofficial wording.

// Honest caveat: the dataset is OCR output parsed by an LLM. Nobody has checked it page by page against the source PDFs and there is no measured accuracy figure. Known-bad entries are listed in the repo README; corrections are ongoing.

NLP // Privacy APPROVED

Persona Clone Pipeline

Anonymising bilingual chat data before it reaches a model

English NER falls over on Latinised Khmer slang, so this does zero-shot entity recognition with an LLM to build a dialect-specific blocklist, scrubs the corpus to [FRIEND] placeholders, then red-teams the resulting persona with 25 adversarial prompts to check it does not leak what it was trained on.
